# Security policy

This repository only holds plugin manifests, launchers and skills. The code that acts on your phone, desktop or
browser lives in each server's repository, which has its own policy:
[NexusAndroid](https://github.com/pironjulien/NexusAndroid/security),
[NexusWindows-Claude](https://github.com/pironjulien/NexusWindows-Claude/security),
[NexusBrowser](https://github.com/pironjulien/NexusBrowser/security).

To report a vulnerability in this marketplace (for example a launcher that runs something other than the pinned
PyPI package), use GitHub's private vulnerability reporting on this repository ("Security" tab → "Report a
vulnerability"). Please do not open a public issue.
